# 游戏玩法与第一版验收标准

本文记录已讨论的设计，不代表功能已经实现。第一版的目标是让四名村民走完一趟探险，而不是先做完职业树。

## 一趟探险

1. **在营地组队。** 营地是招募和休整的大本营。可招募的伙伴不止四人，每次选四人出发。第一版只有村民，可重复招募；不做血药、蓝药或其他道具。
2. **在迷雾里探路。** 第一版用俯视地图表示队伍，不做第一人称。未探索的区域被迷雾遮住，探明后持续显示。移动时会随机遇敌；在同一区域，新路与旧路的遇敌概率相同。熟路的优势是能选近路，不是走起来更安全。
3. **战斗后决定去留。** 随机遇怪后切入战斗，胜利后在原位置继续探索。HP 和施法资源保留战后余量，默认不回复；以后可以由特定技能提供战后恢复。
4. **找到路并活着回来。** 只能经楼梯或已开启的传送点往返，不可随时回程。首层目标是找到深处的传送点，开启并经它回营；不要求清空迷雾或打 Boss。提前从入口楼梯撤回也能保存已获得的进展，下次再来。

## 等待式 ATB

敌我共用一条行动时间轴。队员就绪时，玩家选择技能和目标，整场战斗暂停：敌人不会趁选菜单时出手，其他角色的吟唱和后摇也不会推进。

一次行动按以下顺序结算：

**选定指令 → 前置时间 → 招式生效 → 后摇 → 再次就绪。**

- **前置与后摇分别设定。** 法术的前置表现为吟唱，物理招式的前置表现为蓄力。瞬发等于前置为零，不等于没有后摇。
- **先预览，再确认。** 选择技能和目标时，时间轴明确标出预计命中和再次就绪的位置，与敌我已确定的行动比较。预览不消耗行动或资源；确认后按同一套顺序结算。玩家不必靠猜测或手速抢打断。
- **打断要在前置结束前命中。** 普通伤害不自动打断。带打断效果的招式若及时命中，目标招式取消，只损失时间、不扣法力；目标经过短暂硬直后重新就绪，不承担原招的完整后摇。已生效的招式不能追回。

## 成长、倒地与职业边界

属性随职业成长自动计算，不由玩家分配；升级所得的**技能点由玩家分配**。第一版让村民有少量可选技能，用来验证培养、快慢招式与打断，不在此锁定技能名称或数值。

有人倒地但队伍未全灭时，倒地者不能行动，战后也不会自行站起。其余人可以继续探索；第一版想恢复满员只能回营。以后若队中有学会复活技能的牧师，才有在迷宫里拉起队友的手段。

**后续职业设计，不纳入第一版：** 营地提供固定的基础职业；可学技能与职业相关，但早期怎么加点不限制二转。转职后仍可给自己走过的职业补点，不能学习没走过的分支。例如战士有攻击与防御技能，二转护卫可学援护、嘲讽，也能回头补战士刀技；二转剑客则开放专属剑术。纯坦克和带刀护卫都是允许的培养方向。

## 自动存档与全灭

| 时机 | 结果 |
| --- | --- |
| 每次回营 | 自动保存本次带回的成长、已探地图和传送点进度。 |
| 每次出发 | 自动保存出发状态，包括本次阵容、已分配技能和已有探索进度。 |
| 探险中全灭 | 读档重来，不是救援回营。还原最近的出发存档，不保留此后获得的经验、揭开的地图或新开启的传送点。 |

## 第一版怎样算跑通

- **成功：** 招募并选出四名村民 → 出发存档 → 探图、遇敌并获胜 → 开启深处传送点 → 由此回营。读回营地存档，已探地图和传送点仍在。
- **撤退：** 一名队员倒地，其余人沿楼梯撤回。战后没有自动回血、回蓝或复活；回营后可休整，再次出发时已探路线仍在。
- **失败：** 记下出发时的队伍、经验与地图；探开新区域后全灭。读档后与出发记录一致，失败那趟的变化没有带回来。
- **战斗判定：** 在敌人吟唱期间预览两种不同快慢的行动，比较各自的命中和后摇结束位置。确认赶得上的打断招式后，敌方施法取消、法力不扣；另一次让敌方先完成施法，迟到的打断不得撤销效果。

遇敌率、升级曲线、技能耗蓝、前置和后摇时长等具体数值留待试玩调整。
